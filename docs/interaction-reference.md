## 交互与视觉结构

- 全屏固定画布，页面自然滚动驱动场景、镜头位置与过渡；触控滑动与键盘 PageDown/方向键可用。
- 点击灵光后进入旅程，章节导航可直接跳转，底部进度反映真实滚动位置。
- 桌面鼠标轻量视差；手机采用触控长按，不依赖 hover。
- 长按石碑约 1.4 秒满环触发环境切换；释放、指针取消、失焦、离开场景时清零，重复按住可继续切境；键盘空格/Enter 同样支持。
- 全屏按钮使用 Fullscreen API，鸣谢可关闭并返回原章节，结尾可重新开始或进入原有修炼页面。
- 减少动态效果偏好下关闭持续漂移与大幅镜头变化，保留必要的滚动、长按状态反馈。
- 原修炼页面保留 `/realm`，独立后台保留 `/admin`；原规则和本地数据不被叙事交互改写。
- 视觉：米白纸底、墨黑、青绿、尘蓝、少量朱砂与暖金；粗颗粒干笔美术，全屏留白与稀疏的原生文字控件。
