# 灵石仙宗 Lingshi Realm

颗粒水墨风格的五幕修仙网站。React + Vite，Three.js 水墨星球，Canvas 灵气粒子。先生成所有概念图与物品素材，再实现原生 HTML 文字、点击/滚动镜头、炼丹互动和古风排行榜。

## 本地运行

需要 Node.js 22.12 或以上。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

## 页面与体验

- `/`：太初灵星 → 灵物图鉴 → 我的熔炼炉 → 十丹结金 → 宗门天骄榜。
- 点击星球、场景按钮、底部箭头或章节目录都可推进。首屏点击先让星球加速旋转，再缓慢叠化入境（约3.6秒）；其余点击为约2.4秒连续淡入淡出。滚动沿同一场景顺序推进，镜头使用平滑追踪。
- 图鉴包含灵石和五阶仙物，可逐件点选查看材料、产丹和权重说明。
- 炼丹支持长按蓄力、松开取消，以及点击点火。查询钱包后显示灵石与五阶数量。完成熔炼消耗十个已有低阶材料，获得一个高阶材料，灵石余额保留。缺少材料时显示聚气和不足反馈，不生成丹药。
- 最后一幕为古风长卷榜单。仙阶榜按总权重排序，灵石榜按余额排序，支持完整/部分地址搜索、滚动、前三名、我的洞府标记和详情。
- 洞府详情查看所有仙阶、权重、仙阶与突破记录，可复制完整地址、选择钱包、关闭自动合成、手动进阶。
- `/realm`：旧版已删除，此地址永久重定向到新版首页。
- `/admin`：独立配置后台，修改CA、供应量、5/10分钟周期、Holder余额；立即快照或重置。

## 当前规则与数据边界

默认总供应10亿枚。固定每100,000 LINGSHI计一个修炼单位，向下取整；总供应变化不改变这个固定单位。快照仅在独立后台手动执行。5/10分钟保留为后端调度参考周期，前台不自动执行。排除配置中的系统地址不产丹。

五阶依次为筑基丹、金丹、元婴、化神、渡劫。权重分别为1、12、144、1728、20736。每十个低阶消耗后合成一个高阶，余丹保留，最高阶继续积累。默认自动级联合成；关闭后保留基础丹药，可自行选择某阶手动十合一。开启自动合成会同时处理已经积累的材料。

所有持仓、仙阶、快照和分配领取仍为本地模拟交互，没有真实转账、NFT铸造或链上分配。榜单不会随机变化。最近200条事件来自实际本地快照/合成。钱包熔炼会更新仙阶与权重，不改变灵石余额。未收录钱包的本地查询余额稳定生成并受供应量约束；查询不执行快照或发丹。

当前仍使用全局快照，不实现策划书的逐钱包连续持有计时、成熟资格补发、到账延迟和按日时间权重分配；这些需要持久化后端和链上服务。BNB领取卡仅反馈领取流程，不承诺收益。

状态保存在localStorage，Web Locks串行提交跨标签操作，同轮ID幂等。版本1迁移到版本2时保留持仓、已得筑基丹/金丹、选中地址、历史事件；新增三阶从0开始，旧默认周期升级为5分钟，不追溯补发历史。关闭与重开网页都不触发快照。共享宗门账本和后台鉴权需要后续持久化服务。

## 代码与素材

- `src/engine.js`：单位、五阶、合成、快照、排序、配置与迁移规则。
- `src/store.js`：保存、跨标签同步、钱包查询与后台手动快照。
- `src/holderProvider.js`：独立Holder读取适配器，未来接BSC索引服务。
- `src/journey/`：星球、镜头、图鉴、炼丹、排行榜。
- `src/components/Inventory.jsx`：两处洞府共用仙阶与合成控件。
- `public/images/flow/`：新生成水墨纹理、丹炉、灵石、五阶仙物、洞府背景、透明长卷。
- `public/images/journey/`：原山门等素材。
- `docs/cultivation-journey-design.md`：本轮设计与范围。

生产素材为WebP；未压缩原图和五张概念图保留在本地`design/flow-v2/`，不提交到公开仓库、不上传Vercel。纹理和物品不含参考图水印。三维星球按需加载，不支持WebGL时显示水墨球面后备画面。减少动态效果时关闭持续粒子与装饰动画，保留慢速淡入淡出。环境音由Web Audio合成，默认关闭。

## Holder 接口约定

后台输入 CA 与可选的 Holder 接口地址，保存时自动调用适配器。未配置接口时使用本地数据；配置接口后读取失败会报错并保留旧数据，不回退为模拟余额。

- 批量：`GET <holderApiUrl>?ca=0x...&chainId=56`
- 单钱包：`GET <holderApiUrl>?ca=0x...&chainId=56&address=0x...`
- 批量返回：`{totalSupply: 1000000000, holders: [{address: "0x...", balance: 3400000}], updatedAt: 1791300000000}`
- 单钱包返回批量结构，或 `{address: "0x...", balance: 3400000, updatedAt: 1791300000000}`。

余额为处理 token decimals 后的整数枚数；索引服务须完成全量分页并使用一致区块。适配器有格式校验、15秒超时和错误提示，BSC 索引服务本身尚未接入。浏览器不存 RPC 密钥，系统地址排除使用 excludedAddresses 配置。

全屏空白位置上半屏返回、下半屏前进；输入、按钮、熔炼炉、榜单滚动和洞府弹窗保留自身交互。
