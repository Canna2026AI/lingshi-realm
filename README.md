# 灵石仙宗 · Lingshi Realm

黑金风格的可交互展示网站，React + Vite。项目主视觉先由 Image Gen 生成，随后实现真实 HTML 界面。

## 启动

需要 Node.js 22.12 或更高版本。

```sh
npm install
npm run dev
```

打开终端显示的地址（默认 http://127.0.0.1:5173）。也可以双击 `启动网站.command`。

```sh
npm test        # 8 项核心规则验证
npm run build   # 生成 dist 静态网站
npm run preview # 本地预览构建产物
```

`dist` 可部署至普通静态托管服务；通过 HTTP 访问，不要双击 dist/index.html。

## 展示流程

1. 点击「进入仙宗」选择推荐钱包：3,500,000 枚、0.3500%、3 个修炼单位。
2. 点击「立即快照」：每次增加 3 颗筑基丹。
3. 连续执行 4 轮，获得 1 金丹、2 筑基丹，当前权重 14；天骄榜与动态同步更新。
4. 试选 1,000,000 枚钱包（达到门槛）与 999,000 枚钱包（未达门槛）。
5. 榜单可上下滚动、搜索完整或部分地址、复制完整地址；移动端呈信息卡。
6. 管理后台可编辑地址与余额、供应量、CA、5/10 分钟周期，重新生成 Holder，重置数据。

## 数据与快照

- 按用户最新要求，前台不显示 Demo 与模拟数据标签；实现仍仅使用本地演示数据。
- 20 个格式正确的地址，余额合计 66,759,000 枚，小于十亿总供应。默认 12 个地址达到门槛，每轮共发放 62 颗筑基丹。
- 修炼单位使用 BigInt 整数运算计算 floor(balance × 1000 / supply)，避免浮点数在门槛附近误判。
- 自动结丹：筑基丹累计每 10 颗转为 1 金丹，余丹保留。筑基丹权重 1，金丹权重 12。
- localStorage 保存钱包、配置、丹药、领取状态、下一轮时间、完成轮次和最近 200 条真实执行事件。Web Locks 串行提交跨标签操作。同一轮 ID 幂等。
- 每次手动快照属于独立的新轮次，并从执行时间重新开始周期。重载网页不会重复已完成轮次。
- 自动计时在网页打开时运行；关闭后无后台任务，重新打开时若已到期，只执行当前一次快照，不补发离线历史轮次。
- 动态自动平滑滚动，悬停/聚焦/触摸时暂停。循环区域仅重复已发生记录以实现无缝动画，不生成虚构事件；首次快照前为空状态。
- BNB 卡片提供领取流程反馈，没有真实转账、钱包授权或 NFT 铸造。
- 编辑 Holder 需要点击保存后生效；地址/余额校验、去重和总供应上限校验。更换 CA 会重新加载本地 Holder 并开始新的修炼记录。

## 后续 BSC 数据接口

`src/holderProvider.js` 独立封装 `load()`；默认 `MockHolderProvider`，`BscHolderProvider` 是待实现适配器。未来返回一致区块下的总供应、全量 Holder 地址余额及更新时间，再进行排序与快照。接口提供 chainId=56、CA、excludedAddresses（池子、销毁、项目合约）配置。正式集成时须以 Token decimals/base units 处理余额，并使用持久化服务代替浏览器本地账本。

源文件：`src/engine.js` 规则；`src/store.js` 保存、轮次与计时；`src/components/` 页面组件；`src/styles.css` 样式；`tests/engine.test.js` 测试。品牌素材位于 `brand/`；本地设计参考与验收截图不纳入源码仓库。

## 动效版本

新增灵石浮动、桌面鼠标视差、24/48 个灵气粒子、点击或键盘唤醒涟漪、金色标题与按钮流光、滚动进场、榜单悬停高亮和首席光晕。修炼卡增加十格筑基丹进度、实际发丹数量飘字与金丹扩散光环；成功结丹会显示短暂的全局通知。

特效只读取展示状态，不改变排名、余额或发丹规则。粒子绘制限制在约 30fps，离开可视区域或网页进入后台时暂停；移动端降低粒子数量，系统开启减少动态效果时停止装饰动画。

## 线上网站

公开地址：https://lingshi-realm.vercel.app

2026-10-03 已部署至 Vercel，首次部署状态 READY。构建使用 Vite，输出目录 dist。Vercel 项目为 lingshi-realm，部署配置在 vercel.json；.vercelignore 排除本地设计参考、测试与无关文档。每位访客的修炼与演示状态独立保存在各自浏览器内。

## 独立后台与连击

管理配置位于 `/admin`，首页不再展示管理入口；后台数据仍仅作用于当前浏览器，未接入共享服务端或账户权限。Vercel 为独立后台配置刷新路由。

连续点击灵石，每五次触发一次灵境突破；相邻点击间隔超过 2.2 秒后重新蓄力。每次点击保留独立光波，最多同时展示十组效果。灵境阶数仅为当前页面的视觉状态，不参与丹药、金丹和快照结算。
